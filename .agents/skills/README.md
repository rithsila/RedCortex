| Skill | Purpose |
|-------|---------|
| `rag-engineer` | Design and implement RAG architectures |
| `rag-implementation` | Practical RAG system implementation patterns |
| `vector-database-engineer` | Vector DB design (Qdrant, FAISS) |
| `vector-index-tuning` | Optimize vector indices for performance |
| `search-specialist` | Semantic and hybrid search techniques |

## Usage

These skills are automatically available to the AI agent when working on RedCortex.

To use a specific skill, reference it in your request:
- "Use the rag-engineer skill to improve our retrieval pipeline"
- "Apply python-patterns to refactor the ingestion code"
- "Follow deployment-engineer guidelines for Mac Mini setup"
