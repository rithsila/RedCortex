## Command Quick Reference

### SCALE Commands
```bash
# Validate book configuration
python src/utils/book_config.py validate

# List books with status
python src/utils/book_config.py list

# Dry run batch ingestion
python src/ingestion/batch_runner.py --dry-run

# Run batch ingestion
python src/ingestion/batch_runner.py

# Resume failed ingestion
python src/ingestion/batch_runner.py --resume
```

### SEARCH Commands
```bash
# List categories
python src/utils/category_manager.py list

# Category stats
python src/utils/category_manager.py stats
```

### API Testing
```bash
# Start API
python src/api/main.py

# List categories
curl http://localhost:8000/categories

# Query with category
curl -X POST http://localhost:8000/query \
  -d '{"question": "How to create user?", "categories": ["red_hat"]}'

# Create chat session
curl -X POST http://localhost:8000/chat/sessions \
  -d '{"title": "RHEL Help"}'

# Send message
curl -X POST http://localhost:8000/chat/sessions/sess_123/messages \
  -d '{"message": "How to create user?"}'

# Check metrics
curl http://localhost:8000/metrics
```

### Web UI
```bash
# Start web interface
streamlit run src/web_ui.py
```

## Database Schema Changes

### SCALE-03: Add Categories
```sql
CREATE TABLE categories (
    id INTEGER PRIMARY KEY,
    name TEXT UNIQUE NOT NULL,
    description TEXT,
    icon TEXT
);

ALTER TABLE books ADD COLUMN category_id INTEGER REFERENCES categories(id);
ALTER TABLE chunks ADD COLUMN category_id INTEGER REFERENCES categories(id);
```

### CHAT-01: Add Chat Tables
```sql
CREATE TABLE chat_sessions (
    id TEXT PRIMARY KEY,
    user_id TEXT,
    title TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    archived BOOLEAN DEFAULT 0
);

CREATE TABLE chat_messages (
    id INTEGER PRIMARY KEY,
    session_id TEXT REFERENCES chat_sessions(id),
    role TEXT CHECK(role IN ('user', 'assistant', 'system')),
    content TEXT,
    tokens INTEGER,
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_messages_session ON chat_messages(session_id, timestamp);
```

### PROD-02: Add API Keys
```sql
CREATE TABLE api_keys (
    id INTEGER PRIMARY KEY,
    key_hash TEXT UNIQUE NOT NULL,
    name TEXT,
    tier TEXT DEFAULT 'standard',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_used TIMESTAMP,
    is_active BOOLEAN DEFAULT 1
);
```

## Environment Variables

Add to `.env`:

```bash
# v2.2 Configuration
RED CORTEX_ENV=production  # or development
API_RATE_LIMIT_ENABLED=true
API_AUTH_ENABLED=true
API_AUTH_ADMIN_SECRET=your-admin-secret

# Compression
COMPRESSION_ENABLED=false  # opt-in
COMPRESSION_DEFAULT_RATIO=0.5

# Chat
CHAT_MAX_MESSAGES=5
CHAT_MAX_TOKENS=2000
CHAT_CONTEXT_WINDOW=3

# Logging
LOG_LEVEL=INFO
LOG_FORMAT=json
```
